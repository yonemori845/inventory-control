# 📚 初心者向け開発ガイド

## 🎯 このガイドについて

このガイドは、**プログラミング初心者や非エンジニアの方**が在庫注文管理システムを開発できるように、**分かりやすく丁寧に**説明したものです。

### 📖 ガイドの使い方

1. **このガイドを最初から順番に読み進めてください**
2. **各ステップのチェックボックス（☐）にチェックを入れながら進めてください**
3. **全体の進捗管理には [MASTER_CHECKLIST.md](./MASTER_CHECKLIST.md) を使用してください**
4. **分からないことがあれば、そのステップで一旦停止して調べましょう**
5. **エラーが発生したら、そのステップの「トラブルシューティング」セクションを確認してください**

**💡 ヒント：** [MASTER_CHECKLIST.md](./MASTER_CHECKLIST.md) を開いておくと、全体の進捗を一目で確認できます。

## 環境構築編：開発環境を整える

### ステップ1: Node.jsのインストール

#### なぜ必要？
Node.jsは、JavaScriptをパソコン上で実行するためのソフトウェアです。このシステムはNode.jsを使って動作します。

#### インストール手順

1. **Node.jsの公式サイトにアクセス**
   - ブラウザで [https://nodejs.org/](https://nodejs.org/) を開く

2. **バージョンを選択**
   - 「LTS」と書かれた緑色のボタンをクリック（推奨）
   - LTS = Long Term Support（長期間サポートされる安定版）

3. **インストーラーをダウンロード**
   - 自動的にダウンロードが始まります
   - Windowsの場合は `.msi` ファイル、Macの場合は `.pkg` ファイルがダウンロードされます

4. **インストーラーを実行**
   - ダウンロードしたファイルをダブルクリック
   - 「次へ」をクリックしながら進める
   - 特に設定を変更する必要はありません（デフォルトのままでOK）

5. **インストール完了の確認**
   - コマンドプロンプト（Windows）またはターミナル（Mac）を開く
   - 以下のコマンドを入力してEnterキーを押す：
     ```bash
     node --version
     ```
   - バージョン番号（例: `v20.11.0`）が表示されればOK

#### ✅ チェックポイント

- [ ] Node.jsがインストールされた
- [ ] `node --version` コマンドでバージョンが表示される
- [ ] バージョンが18以上である（推奨：20以上）

#### 🐛 トラブルシューティング

**問題：コマンドが認識されない**
- **解決方法：** パソコンを再起動してみてください。それでも解決しない場合は、Node.jsのインストールをやり直してください。

### ステップ4: Next.jsプロジェクトの作成

#### なぜNext.js？
Next.jsは、Webアプリケーションを作るためのフレームワークです。このシステムはNext.jsを使って作られています。

#### 手順

1. **VSCodeのターミナルを開く**
   - VSCodeの上部メニューから「ターミナル」→「新しいターミナル」をクリック
   - または、キーボードショートカット：`Ctrl + Shift + ``（Windows）または `Cmd + Shift + ``（Mac）

2. **プロジェクトを作成**
   - ターミナルに以下のコマンドを入力してEnterキーを押す：
     ```bash
     npx create-next-app@latest . --typescript --tailwind --app --no-src-dir
     ```
   - **注意：** 最後の `.`（ピリオド）も含めて入力してください。これは「現在のフォルダに作成する」という意味です。

3. **質問に答える**
   - ターミナルにいくつか質問が表示されます：
     - **TypeScriptを使用しますか？** → `Y` と入力してEnter
     - **ESLintを使用しますか？** → `Y` と入力してEnter
     - **Tailwind CSSを使用しますか？** → `Y` と入力してEnter
     - **`src/`ディレクトリを使用しますか？** → `N` と入力してEnter
     - **App Routerを使用しますか？** → `Y` と入力してEnter
     - **インポートエイリアスをカスタマイズしますか？** → `N` と入力してEnter（デフォルトのままでOK）

4. **インストール完了を待つ**
   - 数分かかります。`Installing dependencies...` と表示されている間は待ちましょう

#### ✅ チェックポイント

- [ ] プロジェクトの作成が完了した
- [ ] エラーメッセージが表示されなかった
- [ ] フォルダ内にファイルが作成された（`package.json`、`app`フォルダなど）

#### 🐛 トラブルシューティング

**問題：コマンドが実行されない**
- **解決方法：** インターネット接続を確認してください。また、Node.jsが正しくインストールされているか確認してください。

**問題：エラーが表示される**
- **解決方法：** エラーメッセージをコピーして、Googleで検索してみてください。多くの場合、解決方法が見つかります。

##### 6.3 OAuth認証情報の作成（ユーザー認証用）

1. **認証情報ページを開く**
   - 左側のメニューから「APIとサービス」→「認証情報」をクリック

2. **OAuth同意画面を設定（初回のみ）**
   - 「OAuth同意画面の設定」をクリック
   - ユーザータイプを選択：「外部」を選択して「作成」をクリック
   - アプリ情報を入力：
     - アプリ名：任意の名前（例：在庫管理システム）
     - ユーザーサポートメール：自分のメールアドレス
     - デベロッパーの連絡先情報：自分のメールアドレス
   - 「保存して次へ」をクリック
   - スコープはそのまま「保存して次へ」をクリック
   - テストユーザーは後で追加できるので「保存して次へ」をクリック
   - 「ダッシュボードに戻る」をクリック

3. **OAuth 2.0クライアントIDを作成**
   - 「認証情報を作成」→「OAuth 2.0 クライアント ID」をクリック
   - アプリケーションの種類：「ウェブアプリケーション」を選択
   - 名前：任意の名前（例：在庫管理システム - Web）
   - 承認済みのリダイレクトURI：
     - 「URIを追加」をクリック
     - `http://localhost:3000/api/auth/callback/google` と入力
     - 「作成」をクリック

4. **クライアントIDとシークレットを保存**
   - 表示された「クライアントID」と「クライアントシークレット」をコピー
   - **重要：** この情報は後で使うので、メモ帳などに保存しておいてください

### ステップ7: 環境変数の設定

#### なぜ必要？
環境変数は、機密情報（APIキーなど）を安全に管理するための仕組みです。

#### 手順

1. **`.env.local`ファイルを作成**
   - VSCodeで、プロジェクトのルートフォルダ（`Inventory_Control_2`）に `.env.local` という名前のファイルを作成
   - **注意：** ファイル名の最初に `.`（ピリオド）が付きます

2. **以下の内容をコピー＆ペースト**
   ```env
   # NextAuth設定
   NEXTAUTH_URL=http://localhost:3000
   NEXTAUTH_SECRET=ここに秘密鍵を入力

   # Google OAuth設定
   GOOGLE_CLIENT_ID=ここにクライアントIDを入力
   GOOGLE_CLIENT_SECRET=ここにクライアントシークレットを入力

   # Google Spreadsheet設定
   SPREADSHEET_ID=ここにスプレッドシートIDを入力（後で設定）
   GOOGLE_APPLICATION_CREDENTIALS=./service-account.json
   ```

3. **値を入力**
   - `NEXTAUTH_SECRET`: 秘密鍵を生成します（下記参照）
   - `GOOGLE_CLIENT_ID`: ステップ6.3で保存したクライアントIDを貼り付け
   - `GOOGLE_CLIENT_SECRET`: ステップ6.3で保存したクライアントシークレットを貼り付け
   - `SPREADSHEET_ID`: 後で設定します（今は空欄でOK）

4. **NEXTAUTH_SECRETの生成**
   - Windowsの場合：
     - PowerShellを開く
     - 以下のコマンドを実行：
       ```powershell
       [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes([System.Guid]::NewGuid().ToString()))
       ```
     - 表示された文字列をコピーして、`.env.local`の`NEXTAUTH_SECRET`に貼り付け
   - Mac/Linuxの場合：
     - ターミナルを開く
     - 以下のコマンドを実行：
       ```bash
       openssl rand -base64 32
       ```
     - 表示された文字列をコピーして、`.env.local`の`NEXTAUTH_SECRET`に貼り付け

#### ✅ チェックポイント

- [ ] `.env.local`ファイルが作成された
- [ ] すべての値を正しく入力した
- [ ] `NEXTAUTH_SECRET`が生成された
- [ ] `service-account.json`ファイルがプロジェクトフォルダにある

#### 🐛 トラブルシューティング

**問題：`.env.local`ファイルが作成できない**
- **解決方法：** VSCodeで「ファイル」→「新規ファイル」をクリックして、`.env.local`と入力してください。

**問題：秘密鍵が生成できない**
- **解決方法：** オンラインツール（例：[RandomKeygen](https://randomkeygen.com/)）を使用して、32文字以上のランダムな文字列を生成してください。

##### 8.5 スプレッドシートIDの取得

1. **スプレッドシートを開く**
   - Google Spreadsheetを開きます

2. **URLを確認**
   - ブラウザのアドレスバーに表示されているURLを確認
   - URLの形式：`https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit`
   - `/d/`と`/edit`の間の文字列がスプレッドシートIDです
   - 例：`https://docs.google.com/spreadsheets/d/1ABC123xyz789/edit`
     → スプレッドシートIDは `1ABC123xyz789`

3. **スプレッドシートIDをコピー**
   - スプレッドシートIDをコピーして、メモ帳などに保存

4. **`.env.local`ファイルを更新**
   - VSCodeで`.env.local`ファイルを開く
   - `SPREADSHEET_ID=` の後に、コピーしたスプレッドシートIDを貼り付け

#### ✅ チェックポイント

- [ ] スプレッドシートIDが正しく取得できた
- [ ] `.env.local`ファイルにスプレッドシートIDが設定された

##### 8.6 サービスアカウントに共有権限を付与

1. **サービスアカウントのメールアドレスを確認**
   - ステップ6.4でダウンロードした`service-account.json`ファイルを開く
   - `client_email`の値をコピー（例：`inventory-control@project-id.iam.gserviceaccount.com`）

2. **スプレッドシートに共有権限を付与**
   - Google Spreadsheetの右上の「共有」ボタンをクリック
   - 「ユーザーやグループを追加」欄に、コピーしたメールアドレスを貼り付け
   - 権限を「編集者」に設定
   - 「送信」をクリック

3. **共有権限の確認**
   - 共有設定で、サービスアカウントが「編集者」として表示されていることを確認

#### ✅ チェックポイント

- [ ] サービスアカウントのメールアドレスが正しく取得できた
- [ ] スプレッドシートにサービスアカウントが「編集者」として追加された

## 動作確認編：動作を確認する

### ステップ9: 開発サーバーの起動

#### 手順

1. **VSCodeのターミナルを開く**
   - VSCodeで「ターミナル」→「新しいターミナル」をクリック

2. **開発サーバーを起動**
   - 以下のコマンドを入力してEnterキーを押す：
     ```bash
     npm run dev
     ```

3. **起動を待つ**
   - `- Local: http://localhost:3000` と表示されるまで待ちます（数十秒）

4. **ブラウザで確認**
   - ブラウザで `http://localhost:3000` にアクセス
   - Next.jsのデフォルトページが表示されればOK

#### ✅ チェックポイント

- [ ] 開発サーバーが起動した
- [ ] ブラウザでページが表示された
- [ ] エラーが表示されなかった

#### 🐛 トラブルシューティング

**問題：エラーが表示される**
- **解決方法：** エラーメッセージを確認してください。よくあるエラー：
  - `.env.local`ファイルが見つからない → ファイルが正しい場所にあるか確認
  - ポート3000が使用中 → 他のアプリケーションを終了するか、別のポートを使用

**問題：ページが表示されない**
- **解決方法：** ブラウザのアドレスバーに `http://localhost:3000` と正確に入力してください。

### ステップ10: 認証機能のテスト

#### 手順

1. **ログインページにアクセス**
   - ブラウザで `http://localhost:3000/api/auth/signin` にアクセス
   - Googleログインボタンが表示されればOK

   - ログインボタンをクリック

#### ✅ チェックポイント

- [ ] `/api/auth/signin`にアクセスできる
- [ ] Googleログインボタンが表示される
- [ ] ログインが正常に動作する（オプション）

#### 🐛 トラブルシューティング

**問題：ログインボタンが表示されない**
- **解決方法：** `.env.local`ファイルの`GOOGLE_CLIENT_ID`と`GOOGLE_CLIENT_SECRET`が正しく設定されているか確認してください。

**問題：ログインエラーが発生する**
- **解決方法：** Google Cloud Consoleで、リダイレクトURIが `http://localhost:3000/api/auth/callback/google` に設定されているか確認してください。
