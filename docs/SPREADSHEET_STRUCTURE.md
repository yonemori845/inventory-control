## 🔍 列構成の診断

スプレッドシートの列を変更した場合、次のAPIでコードとの整合性を確認できます。

- **全シートのヘッダー確認**: `http://localhost:3000/api/test-sheets/all`
- **詳細診断（期待する列名との照合）**: `http://localhost:3000/api/test-sheets/diagnose`

`diagnose` では、各シートの実際のヘッダーと、コードが期待する列名の照合結果が表示されます。

### productsシートの構造

**⚠️ 重要：列の順序を変えないでください。** 新規商品追加時は、以下の順序でデータが書き込まれます。

| 列順 | 列名（日本語） | 列名（英語） | 説明 |
|------|--------------|------------|------|
| A | 商品ID | productId | 商品の一意のID |
| B | 商品名 | name | 商品の名前 |
| C | 画像URL | imageUrl | 商品画像のURL（オプション） |
| D | サイズ | size | 商品のサイズ（オプション） |
| E | 商品コード | productCode | 商品コード（オプション） |
| F | JANコード | barcode | バーコード（JANコード） |
| G | 税抜価格 | priceExclTax | 税抜き価格（オプション） |
| H | 税込価格 | price | 税込み価格（メインの価格） |
| I | 作成日時 | createdAt | 作成日時 |
| J | 更新日時 | updatedAt | 更新日時 |

**列の追加・削除・並び替えをすると、データがずれて正しく表示されません。**
