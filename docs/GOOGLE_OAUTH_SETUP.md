# 🔐 Google OAuth設定ガイド

このガイドでは、Google OAuthの**クライアントID**と**クライアントシークレット**を取得して設定する方法を詳しく説明します。

---

## 📍 クライアントシークレットの確認場所

**Google Cloud Console**の「認証情報」ページで確認できます。

---

## 🚀 ステップバイステップ手順

### ステップ1: Google Cloud Consoleにアクセス

1. **ブラウザでGoogle Cloud Consoleを開く**
   - [https://console.cloud.google.com/](https://console.cloud.google.com/) にアクセス
   - Googleアカウントでログイン

2. **プロジェクトを選択**
   - 画面上部の「プロジェクトを選択」をクリック
   - 使用するプロジェクトを選択（まだ作成していない場合は、先にプロジェクトを作成してください）

---

### ステップ2: 認証情報ページに移動

1. **左側のメニューから「APIとサービス」をクリック**
   - メニューが表示されていない場合は、左上の「☰」（ハンバーガーメニュー）をクリック

2. **「認証情報」をクリック**
   - 「APIとサービス」→「認証情報」の順にクリック

---

### ステップ3: OAuth 2.0クライアントIDを確認

#### 3.1 既に作成済みの場合

1. **「OAuth 2.0 クライアント ID」セクションを確認**
   - 認証情報ページの中央に表示されています
   - 「OAuth 2.0 クライアント ID」というセクションを探します

2. **クライアントIDをクリック**
   - 作成済みのOAuth 2.0クライアントIDの名前をクリック
   - 例: 「在庫管理システム - Web」など

3. **クライアントIDとシークレットを確認**
   - 画面に以下の情報が表示されます:
     - **クライアントID**: `123456789-abcdefghijklmnop.apps.googleusercontent.com` のような形式
     - **クライアントシークレット**: `GOCSPX-xxxxxxxxxxxxxxxxxxxx` のような形式

#### 3.2 まだ作成していない場合

1. **「認証情報を作成」ボタンをクリック**
   - 認証情報ページの上部にある「認証情報を作成」ボタンをクリック

2. **「OAuth 2.0 クライアント ID」を選択**
   - ドロップダウンメニューから「OAuth 2.0 クライアント ID」を選択

3. **OAuth同意画面の設定（初回のみ）**
   - まだOAuth同意画面を設定していない場合、設定画面が表示されます
   - **ユーザータイプ**: 「外部」を選択して「作成」をクリック
   - **アプリ情報**:
     - アプリ名: 任意の名前（例: `在庫管理システム`）
     - ユーザーサポートメール: 自分のメールアドレス
     - デベロッパーの連絡先情報: 自分のメールアドレス
   - 「保存して次へ」をクリック
   - スコープはそのまま「保存して次へ」をクリック
   - テストユーザーは後で追加できるので「保存して次へ」をクリック
   - 「ダッシュボードに戻る」をクリック

4. **OAuth 2.0クライアントIDを作成**
   - 再度「認証情報を作成」→「OAuth 2.0 クライアント ID」をクリック
   - **アプリケーションの種類**: 「ウェブアプリケーション」を選択
   - **名前**: 任意の名前（例: `在庫管理システム - Web`）
   - **承認済みのリダイレクトURI**:
     - 「URIを追加」をクリック
     - `http://localhost:3000/api/auth/callback/google` と入力
     - 「作成」をクリック

5. **クライアントIDとシークレットをコピー**
   - 作成後、以下の情報が表示されます:
     - **クライアントID**: コピーボタンをクリックしてコピー
     - **クライアントシークレット**: 「表示」をクリックしてからコピー
   - **重要:** この情報は後で使うので、メモ帳などに保存しておいてください

---

### ステップ4: `.env.local`に設定

1. **VSCodeで`.env.local`ファイルを開く**
   - プロジェクトフォルダの`.env.local`ファイルを開く

2. **クライアントIDを設定**
   ```env
   GOOGLE_CLIENT_ID=123456789-abcdefghijklmnop.apps.googleusercontent.com
   ```
   - `your-google-client-id`の部分を、コピーしたクライアントIDに置き換え

3. **クライアントシークレットを設定**
   ```env
   GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxxxxxxxxxx
   ```
   - `your-google-client-secret`の部分を、コピーしたクライアントシークレットに置き換え

**完成例:**
```env
# Google OAuth設定（Google Cloud Consoleで取得）
GOOGLE_CLIENT_ID=123456789-abcdefghijklmnop.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxxxxxxxxxx
```

## 🔍 クライアントシークレットが見つからない場合

### 確認ポイント

1. **正しいプロジェクトを選択しているか確認**
   - 画面上部の「プロジェクトを選択」で、正しいプロジェクトが選択されているか確認

2. **OAuth 2.0クライアントIDが作成されているか確認**
   - 認証情報ページに「OAuth 2.0 クライアント ID」が表示されているか確認
   - 表示されていない場合は、ステップ3.2の手順で作成してください

3. **クライアントIDをクリックして詳細を表示**
   - クライアントIDの名前をクリックすると、詳細画面が表示されます
   - 詳細画面に「クライアントシークレット」が表示されます
   - 「表示」ボタンをクリックすると、シークレットが表示されます

---

## 🔐 セキュリティに関する注意事項

### ⚠️ 重要な注意点

1. **クライアントシークレットは秘密情報です**
   - 他人に共有しないでください
   - GitHubなどの公開リポジトリにコミットしないでください
   - `.env.local`ファイルは`.gitignore`に含まれているので、通常は問題ありませんが、確認してください

2. **シークレットを紛失した場合**
   - Google Cloud Consoleで再生成できます
   - 古いシークレットは無効になります

3. **シークレットを再生成する方法**
   - 認証情報ページで、OAuth 2.0クライアントIDをクリック
   - 「クライアントシークレットをリセット」をクリック
   - 新しいシークレットが生成されます
   - `.env.local`を更新してください

## 🧪 動作確認

設定が完了したら、以下で動作確認できます：

1. **開発サーバーを起動**
   ```powershell
   npm run dev
   ```

2. **ログインページにアクセス**
   ```
   http://localhost:3000/login
   ```

3. **「Googleでログイン」ボタンをクリック**
   - Google認証画面が表示されればOK
   - ログインが成功すれば、設定は正しく完了しています

## 🐛 よくあるエラー

### エラー1: `redirect_uri_mismatch`

**原因:** リダイレクトURIが正しく設定されていない

**解決方法:**
1. Google Cloud Consoleの認証情報ページで、OAuth 2.0クライアントIDをクリック
2. 「承認済みのリダイレクトURI」に以下が追加されているか確認:
   ```
   http://localhost:3000/api/auth/callback/google
   ```
3. 追加されていない場合は、追加してください

### エラー2: `invalid_client`

**原因:** クライアントIDまたはシークレットが間違っている

**解決方法:**
1. `.env.local`の`GOOGLE_CLIENT_ID`と`GOOGLE_CLIENT_SECRET`が正しいか確認
2. 余分なスペースや引用符がないか確認
3. Google Cloud Consoleで、正しい値をコピーして再度設定してください
