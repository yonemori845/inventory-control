## 1. 使う前に確認すること

### ✅ 環境の確認

バーコードスキャンは**カメラ**を使うため、次の条件を満たしている必要があります。

| 確認項目 | 説明 |
|----------|------|
| **カメラ付きデバイス** | パソコン（Webカメラ）またはスマートフォン・タブレット |
| **HTTPS または localhost** | カメラはセキュリティのため、`https://` のサイトか `http://localhost` でのみ使えます |
| **ブラウザ** | Chrome、Edge、Safari など、最新版を推奨 |

> 💡 **パソコンで開発中の場合**  
> `npm run dev` で起動した `http://localhost:3000` に、**同じパソコンのブラウザ**でアクセスすると使えます。
>
> ⚠️ **iPhone からは localhost にアクセスできません**（詳しくは[次のセクション](#2-iphoneで使うにはhttpsの取得方法)へ）

### ✅ カメラの許可

初めてスキャンを開始すると、ブラウザから**カメラへのアクセス許可**を求められます。

- 「**許可**」を選んでください
- 「ブロック」にすると、スキャン機能は使えません

## 2. iPhoneで使うには？（HTTPSの取得方法）

**「iPhoneのカメラでバーコードスキャンを使いたい」** という方のために、詳しく説明します。

### 🤔 なぜ iPhone でうまくいかないのか？

ブラウザのセキュリティルールで、**カメラを使うには次のどちらかが必要**です：

- `https://` で始まるアドレス（例：`https://example.com`）
- `http://localhost`（**パソコンで開いている場合のみ**）

**重要なポイント**：

- iPhone の Safari で `http://localhost:3000` と入力しても**うまくいきません**
- 「localhost」は「**この端末自身**」を指す言葉です
- つまり iPhone では「iPhone 自身の 3000番ポート」にアクセスしてしまい、アプリはパソコンで動いているため**つながりません**
- さらに、`http://192.168.1.100:3000` のように**同じWi-Fi内のパソコンのIPアドレス**でアクセスしても、**カメラは使えません**（`http://` は localhost 以外ではカメラ非対応のため）

**結論**：iPhone でカメラを使うには、**HTTPS のアドレス**が必要です。

---

### ✅ 解決方法：2つの選択肢

iPhone で使うには、次のどちらかの方法で **HTTPS のURL** を用意します。

---

#### 方法A：Vercel にデプロイする（おすすめ・本番運用向け）

Vercel は無料で使えるホスティングサービスで、デプロイすると自動で `https://あなたのアプリ名.vercel.app` のような HTTPS のURLが付きます。iPhone からこのURLにアクセスすれば、カメラが使えます。

> 📖 **詳しい手順は [Vercel デプロイ ステップバイステップガイド](./VERCEL_DEPLOY_GUIDE.md) を参照してください。**  
> 初めての方でも分かるように、画面の操作から環境変数の設定、Google OAuth の更新まで、すべての手順を丁寧に説明しています。

---

#### 方法B：ngrok で開発中にテストする（開発向け）

開発中に「パソコンで動かしているアプリを、iPhone から HTTPS で試したい」場合は、**ngrok** が便利です。ngrok は、インターネット経由の HTTPS のURL を、あなたのパソコンの localhost に転送してくれます。

##### 手順

1. **ngrok のアカウント作成とインストール**

   - [https://ngrok.com](https://ngrok.com) にアクセス
   - 無料でアカウント作成
   - ダウンロードページから、自分のOS用の ngrok をインストール

2. **開発サーバーを起動**

   ```bash
   npm run dev
   ```

   `http://localhost:3000` で動いていることを確認します。

3. **ngrok でトンネルを開始**

   新しいターミナル（コマンドプロンプト）を開き、次を実行：

   ```bash
   ngrok http 3000
   ```

4. **表示された URL をメモする**

   ターミナルに、次のような表示が出ます：

   ```
   Forwarding   https://abcd1234.ngrok-free.app -> http://localhost:3000
   ```

   **`https://` で始まる方のURL**（例：`https://abcd1234.ngrok-free.app`）をコピーします。

5. **Google OAuth のリダイレクトURIを一時的に追加**

   - Google Cloud Console → 認証情報 → OAuth 2.0 クライアントID
   - 「承認済みのリダイレクトURI」に次を追加：
     - `https://abcd1234.ngrok-free.app/api/auth/callback/google`
     - ※ `abcd1234` の部分は、実際に表示された ngrok のURLに合わせてください
   - 保存

6. **iPhone からアクセス**

   - iPhone の Safari で、メモした `https://xxxx.ngrok-free.app` を開く
   - ログインして、バーコードスキャンを試す

##### ⚠️ ngrok の注意点

- **無料プラン**：毎回 ngrok を起動するたびにURLが変わります
- URLが変わったら、その都度 Google OAuth のリダイレクトURIを更新する必要があります
- 有料プランでは固定URLを利用できます

---

### 📌 iPhone 用のまとめ

| 方法 | 向いている人 | URLの例 |
|------|---------------|---------|
| **Vercel にデプロイ** | 本番・日常的に使いたい人 | `https://xxx.vercel.app`（固定） |
| **ngrok** | 開発中に少しだけiPhoneで試したい人 | `https://xxxx.ngrok-free.app`（無料は都度変化） |

どちらの方法でも、**HTTPS のURL** を取得できれば、iPhone のカメラでバーコードスキャンが使えます。

## 3. バーコードスキャンが使える場所

バーコードスキャンは、次の **3つの画面** で使えます。

| 画面 | 場所 | 何ができるか |
|------|------|--------------|
| **新規注文** | 注文一覧 → 新規注文 | スキャンした商品をカートに追加 |
| **在庫管理** | 在庫一覧 | スキャンした商品の在庫編集画面へ移動 |
| **商品登録** | 商品一覧 → 新規商品追加 | JANコード欄にスキャン結果を自動入力 |

---

## 4. 使い方（場面別）

### 📦 場面A：新規注文で商品を追加する

**やりたいこと**：バーコードを読み取って、その商品を注文カートに追加する

#### 手順

1. **ログイン**して、ホーム画面を開く
2. **「受注管理」** をクリック
3. **「新規注文」** をクリック（または注文一覧から「新規注文」）
4. **「バーコードスキャンで商品を追加」** ボタンをクリック
5. **「スキャンを開始」** をクリック
6. カメラが起動したら、**バーコードをカメラの枠内に合わせる**
7. 読み取りに成功すると、自動で**カートに商品が追加**され、スキャン画面が閉じます
8. 同じ商品を追加したい場合は、もう一度「バーコードスキャンで商品を追加」からスキャンする

#### ポイント

- 商品マスタに登録されている JANコード の商品だけ追加できます
- 見つからない場合は「該当する商品が見つかりませんでした」と表示されます
- その場合は、商品マスタにその JANコード の商品を登録してから、もう一度スキャンしてください

---

### 📊 場面B：在庫管理で商品を検索する

**やりたいこと**：バーコードを読み取って、その商品の在庫編集画面を開く

#### 手順

1. **ログイン**して、ホーム画面を開く
2. **「在庫管理」** をクリック
3. **「バーコードで在庫を検索」** ボタンをクリック
4. **「スキャンを開始」** をクリック
5. カメラが起動したら、**バーコードをカメラの枠内に合わせる**
6. 読み取りに成功すると、自動で**その商品の在庫編集画面**に移動します
7. 在庫数や最小在庫を変更して保存できます

#### ポイント

- 商品マスタに登録されていないバーコードの場合は、「該当する商品が見つかりませんでした」と表示されます

---

### 🏷️ 場面C：商品登録でJANコードを入力する

**やりたいこと**：新規商品を登録するとき、バーコードを読み取って JANコード 欄に自動入力する

#### 手順

1. **ログイン**して、**「商品マスタ」** → **「新規商品追加」** を開く
2. 商品名など、必要な項目を入力する
3. **「JANコード（バーコード）」** の右側にある **「スキャン」** ボタンをクリック
4. **「スキャンを開始」** をクリック
5. カメラが起動したら、**バーコードをカメラの枠内に合わせる**
6. 読み取りに成功すると、**JANコード欄に自動で入力**され、スキャン画面が閉じます
7. あとは他の項目を入力して、「登録する」をクリック

#### ポイント

- 商品マスタに登録済みかどうかは関係なく、バーコードの値だけを入力します
- 手入力でも構いませんが、スキャンの方がミスが減ります

## 5. よくあるトラブルと解決方法

### ❌ 「カメラへのアクセスが許可されていません」

**原因**：ブラウザのカメラ許可が「ブロック」になっている

**解決方法**：

1. ブラウザのアドレスバー左側の **鍵マーク（またはカメラマーク）** をクリック
2. カメラの設定を **「許可」** に変更
3. ページを再読み込み（F5 キー）して、もう一度スキャンを試す

または、ブラウザの設定からサイトごとのカメラ許可を変更してください。

---

### ❌ 「カメラを起動できませんでした。HTTPSまたはlocalhostでお試しください。」

**原因**：`http://` の通常のサイト（localhost 以外）では、セキュリティ上カメラが使えない

**解決方法**：

| 利用状況 | 対処 |
|----------|------|
| **パソコンのブラウザで開発中** | `http://localhost:3000` でアクセスしているか確認 |
| **iPhone やスマホで使いたい** | [セクション2「iPhoneで使うには？」](#2-iphoneで使うにはhttpsの取得方法)を参照し、Vercel デプロイまたは ngrok で HTTPS のURLを用意する |
| **本番運用** | Vercel などにデプロイして `https://` のURLで公開する |

---

### ❌ カメラは起動するが、バーコードが読み取れない

**考えられる原因と対処**：

| 原因 | 対処 |
|------|------|
| 光の反射・影 | 照明を調整する、角度を変える |
| バーコードが小さい・ぼやけている | カメラを近づける、ピントを合わせる |
| 対応していない形式 | JAN/EAN、QRコードなど一般的な形式を試す |
| カメラの解像度 | 別のブラウザやデバイスで試す |

---

### ❌ 「該当する商品が見つかりませんでした」（注文・在庫の場合）

**原因**：スキャンしたバーコード（JANコード）の商品が、商品マスタに登録されていない

**解決方法**：

1. **商品マスタ** で、その JANコード の商品が登録されているか確認
2. 登録されていなければ、**「新規商品追加」** で商品を登録
3. 登録後、もう一度スキャンを試す

---

### ❌ スキャン後、同じバーコードをすぐに読み取れない

**原因**：連続スキャンを防ぐため、同じバーコードは **2秒間** 無視される仕様です

**対処**：2秒以上待ってから、もう一度スキャンしてください

---

## 📌 まとめ

1. **カメラ付きデバイス** と **HTTPS または localhost** が必要
2. 初回はブラウザの **カメラ許可** を「許可」にする
3. **新規注文**・**在庫管理**・**商品登録** の3つの画面で使える
4. 商品を検索する機能（注文・在庫）では、**商品マスタに登録済み**の商品だけ対象

不明な点があれば、開発チームにお問い合わせください。
